### P1 — Notes stay off the object
- **What**: Session tile has no note surface; I8 forbids a second composer.
- **Why**: Correct law, incomplete path — writing a note on the carton still feels like chatting.
- **Fix**: Write-target chip on the main composer when a session is armed (already sketched as `composerTarget`).

### P2 — Park / Start still fight the density

- **Why**: Geometry tween on a scan floor; Park is easy to miss.
- **Fix**: Drop scale; keep colour/opacity. Park stays a verb, quieter than Start.
- **Command**: /harden (motion) then /quieter
