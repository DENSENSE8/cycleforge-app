# Cycle Forge — agent instructions

Portable hard rules for every coding agent (Claude, Grok, Codex, Cursor, …).
**This file is a map, not a manual.** Each row below links the file that holds the detail — read it
when the task touches that concern. Depth lives in [`.claude/rules/`](.claude/rules/), never here.

## Product

**Cycle Forge** is multi-tenant reseller-ops SaaS. This repo is the app; USAV is the dogfood tenant.
Vendor integrations (Zoho, Zendesk, …) are tenant connectors behind **capability facades** — never the
product itself. Operator copy uses capability nouns or runtime provider labels, never hardcoded vendor
product sentences (except the Integrations hub / deep links).

## Hard laws

Violating one of these is a bug even when the task "worked". Detail behind the links above.

- **Never commit `.env`**, and never bypass the hooks in `.claude/settings.json`.
- **Never start, restart, or kill a dev server.** The user's is already running on **`:3050`** —
  attach to it. A broken dev server is a thing you report, not a thing you repair.
- **The user manages commits.** Never `git stash`; stage only your own files; commit/push only when asked.
- **Stay on the checkout's branch.** The worktree *is* the branch — no ad-hoc branches, no mid-session switches.
- **One module per concern.** Read from the SoT; never inline, copy, or re-derive its mapping.
- **Compose from the named SoT first; grow it when it is wrong.** Never fork a page-local twin for the same job.
- **Mount-gated URL opens paint via `useOptimisticUrlParam` / `resolveOptimisticParam`** — never a feature-local pending twin waiting on soft-replace. Sync-guard refs (`useDashboardSelectedOrder`, `useReceivingWorkspacePane`) are a different job. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Optimistic URL-param paint.
- **Platform-aware order / PO identity is one contract:** resolve label + paint from `source-platform.ts` / `usePlatformMeta`; hover reads `Platform full-id`, the face stays last-8, copy stays bare, and unknown stays neutral. Never concatenate or color-map platform identity in a view. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Source platform · Copy-chip.
- **Order surfaces are two jobs, not one shell.** Durable edit/notes = desk `ShippedDetailsPanel` (index→leaf) @ `/shipping/orders?openOrderId=`; search feedback = `SearchOrderFeedback` @ `/search?sel=order:…` (never import `ShippedDetailsPanel`). `/o/[id]` is retired (redirects to search feedback). Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md).
- **Search order feedback identity** — disposition + facts use `OrderIdChip` / `PlatformMark` / `TrackingChip` (last-8, platform tooltip); never `Order #…` prose, yellow platform pills, or bare mono for marketplace ids. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Search order feedback identity.
- **Status changes only via `transition()`** — never a raw `UPDATE … current_status`.
- **Cross-entity urgency resolves in one place** — `promoteUrgency()` (`src/lib/urgency/`), a binary `urgent | normal` rung over order · carton · ticket, compare-and-set. Richer per-record scales stay in their own modules, and `order_flags.flag = 'priority'` is triage tint, not urgency. Never a new single-purpose urgency writer. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Cross-entity urgency.
- **`orgId` comes from `ctx`, never the body**; org-scoped writes go through `withTenantTransaction`.
- **Never build a second search engine, audit API, or status transition** outside the SoT modules.
- **Color, spacing, type, z-index, elevation, focus come from tokens** — no page-local hex, no raw `z-[N]`.
- **Motion comes from `@/design-system/motion`** — name a `motionRole.*`, never a motion package.
  `framer-motion` / `motion/react` are banned outside `src/design-system/motion/**`.
- **Unbox centre (main dogfood): PO lines + label preview** — carton context sticky; `POUnboxingSection` (PO meta ledger; chips focus the dock; **active line** mounts progressive Condition → Serial → Photos for mouse go-back — dual loci with the dock) + `UnboxLabelPreview` + Placement (`UnboxPlacementSection` after print). Bottom dock is `UnboxDockHost` — flush **two-band floor** instrument (`w-full` · host `gap-0`/`p-0` · every control is a full-height abutting segment — **never** content-sized chips / soft pills / `gap-*` air in dead white): Band 1 = Active Step Studio (CTA · wedge; trailing null; after print arms location-scan `stage`); dogfood always-on Print·Receive on `data-unbox-dogfood-print` above the host (Displays-independent); Band 2 = full-width pager (left) · flush procedure-% cell (right — `UnboxScanProgressControl` `variant="floor"`). That procedure-% control is the floor's ONLY metric — no vanity aggregate KPIs, never `GoalRing`. Capture trio **Serial → Condition → Photos**; commit **print → stage → receive**. Centre `ProcedureDeck` stays parked. Per-step ACTION/`railLeaf` + sibling port pattern: [`display/unbox-station.md`](.claude/rules/display/unbox-station.md) · [`display/station-port-from-unbox.md`](.claude/rules/display/station-port-from-unbox.md). Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Unbox centre (main) · Unbox dock flush floor. Guard: `unbox-dock-one-shell.guard.test.ts`.
- **Received meters mean inventory-confirmed qty** via `inventoryReceivedDisplayQty` — Unboxed ≠ Received; never paint a Received label from raw `quantity_received` (Unboxed at floor `1/1` → display `0/expected`, empty bar). Qty tips use **counted** (`floorQtyFractionTip`); status-dot emerald is stage-only (not qty-complete). Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Unboxed ≠ Received.
- **Scan-station centre = ops-flow only** — the carton's PO items / unfound lines (`LinePoItemsSection` / `UnmatchedItemsSection`) under identity, dock below — exact triage / I/O for that station. **Never** centre advisory banners, “needs attention” strips, ticket history, or dossier summaries; those open as right-edge **Displays** (`StationDisplaysPushStack` / `StationDisplaysPushColumn`) beside the middle (Ticket · Photos · Pairing · …), never a centre `SectionTabsSlider` and never a `RightRailHost` occupant. **Arrival port:** centre = one white door-flow plane (items without units chrome + Classify); Staging = flush dock Band 1; Displays = Pairing only. Operator copy: **Open displays** ≠ Desk Band 3 **Show inspector** (never “details editor” on the Station `←|`). Unbox is the golden; Arrival · Testing compose the same host. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Scan-station centre lines display · Displays vs inspector. Guard: `station-centre-ops-flow.guard.test.ts`.
- **Station Action vs Context planes** — one domain SoT (status machine · exceptions · inventory); every scan station’s Displays = Action (keyboard/wedge · dense fact rows); Workbench table/inspector = Context (queue metrics). Never dual domain stores. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Station Action vs Context planes.
- **Pack placement (Ready-to-Pack)** — packing desks are `locations` (`location_kind` DESK/STAGING); current order place = `order_pack_placements`, loose-unit place = `unit_pack_placements` (`src/lib/packing/*pack-placement.ts`) — SEPARATE ledgers + counts on the same benches, never merged, never a parallel packing_stations table or localStorage workstation as count SoT. Place at tech TRACKING scan (order) / unit-id sticker (unit); both clear on pack complete (`/api/pack/ship`). Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Pack placement.
- **Displays leaf verbs are armed rows + URL drills** — never a nested parent `TabDisplay` underline for leaf-level actions (Photos golden: `PhotosActionsArmedList` → `?photoAction=`); child `segment` only inside a tool; Inventory stays secondary vertical. - **Nav keys are ONE leader-armed selection keyboard** — `⌘;` arms a region (Left · Middle · Right); a stable single **letter** jumps + commits an **actionable** target (never a bare digit — wedge law; never a display metric / progress ring / telemetry — those are read-only, not jump targets — including the Unbox floor's one compact procedure-% control, which is a click/hover control under the dock, not a letter-jump target). One owner (`src/lib/keyboard/nav-keys/`, grows `useArmedCursorList`); wedge-safe (overlay-yield · burst-detect · refuse-in-input · auto-disarm). Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Nav keys.
- **Station scan bar: Insert reclaim · ⌘. next scan** — `src/lib/scan-hotkey/` owns Insert/F\* (focus) and **⌘. / Ctrl+.** (clear + focus the mounted `StationScanBar` — arm next carton). Dock wedge focus stays `receiving-focus-scan` / `⌘; m → s` — never overload ⌘. for the dock. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Station scan bar chords · [`station-scan-bar-and-keyboard-gaps-HANDOFF.md`](docs/todo/station-scan-bar-and-keyboard-gaps-HANDOFF.md).
- **Workbench spreadsheets mount via the table definition registry + `NonlinearTableHost`** over the `LedgerGridSurface` engine — pages supply feed + intents + renderers only; the shell recipe, prefs bucket and column model resolve from a Zod-validated `TableDefinition` (`ariaLabel`/`testId`/`tableId` overridable as instance identity, never `surface`). Never a page-local `*GridView` twin for the same job; domain cell maps stay per `entityFamily`. AI may author Zod definitions only — never cell JSX, DDL, or new terminal statuses. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Table definition registry.
- **Table-engine fan-out dogfoods Unbox History first** — a new spreadsheet capability (custom columns, shell geometry, cell-map seams, Fields verbs) lands on `ReceivingGridHost` / History and is operator-verified before any other `entityFamily` (Orders, Catalog, …). Never port N queues in one pass. Live custom-field entities = `CUSTOM_FIELD_LIVE_ENTITY_TYPES` only. Guard: `custom-fields-history-first.guard.test.ts`. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Table engine fan-out (History first).
- **LedgerGrid justification:** a **magnitude** you compare down the column (qty · price · date) **end**-aligns; a **label or ID** you read (title · tag · platform · tracking · order # · SKU · serial) **start**-aligns — `resolveGridColumnAlign` only (never a per-cell `justify-*`).
- **Depth is planes, not floating gutters** — work columns are exact/flush on one shared canvas; depth = surface steps (`canvas` → `sunken` → `card`) + `elevationClass` + `nestedCorner`. Decorative outer `m-*` islands between spine · context · center · right are not depth. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Depth elevation · Frame column budget.
- **Frame width budget** — open rails must leave the center floor on desk surfaces (`MIN_WORK_SURFACE_PX`); scan stations lock the middle at **720** (`STATION_PUSH_CENTER_FLOOR_PX`) with Displays as a `flex-1` invader that always fills leftover (`StationScanPaneHost` / `StationDisplaysPushColumn` — Flex-Grow Sandwich; no hard-coded host gutters). Middle **content** is edge-to-edge (`STATION_WORKBENCH_COLUMN`; Unbox golden; sibling ratchet + CI loop in `station-edge-measure.guard.test.ts`). Never dual full-width right columns (AI + ticket/detail). Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Frame column budget.
- **The left context column is EARNED, not a default.** Scan stations = recents rail; `master-detail` workbench = record picker; **`ops-queue` desk triage = rail-less (Pattern E)** — tabs own stage, KPI owns attention, and this surface's saved filter combinations own a page-scoped **Views** control in **Band 3 trailing find** (`WorkbenchViewsMenu`, flush Lucide Bookmark icon); personal scope (My queue) is the right-inspector staff filter. Never a left rail that restates a tab / KPI facet, never a monitor rollup or onboarding card in a working triage rail.
- **A control's SCOPE decides its home — three pin scopes never share a trigger or store**: website-wide page-pin (`HeaderPinsSwitcher` / `useQuickAccess`, GlobalHeader, unconditional on every route) · station Band-1 strip list-pin (`UnboxAddListPopover` / `unboxPinnedExtraTabs`, leading Pin cube when a closed catalog exists) · page-wide Views (`WorkbenchViewsMenu` / `useSavedViews`, Band 3 trailing find). Never merge, gate, or tab-merge them; never grow the page-pin a second dropdown for Views or list-pin. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Left-edge occupant → *A control's SCOPE decides its home*. Guard: `outbound-rail-dedup.guard.test.ts`.
- **Workbench Band-1 = fixed process/system tabs for every staffer** — optional foreign collections only via a closed Pin-list (+ staff→role→org defaults, cap 2); never Chrome-style pin/unpin of system stages; strip membership ≠ `saved_views`. Pin-list cube is earned when the surface has a closed catalog; otherwise omit (honest absence). Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Workbench Band-1 strip · [`display/workbench-ops-queue.md`](.claude/rules/display/workbench-ops-queue.md). Guard: `unbox-pinned-inbound.guard.test.ts`.
- **The right edge PUSHES; it never floats over the work surface** (ruled 2026-08-05, superseding the narrow overlay fallback). MasterNav is a push spine; context rails use `ContextPanelLayout` (resize + collapse); desktop right-rail record inspectors stay in-flow on `RightRailHost` (`modal={false}`, resize + collapse) at every width. Width pressure **never auto-closes / parks the left context rail** — both stay open; desk inspectors cap so the center keeps `MIN_WORK_SURFACE_PX`; scan-station Displays let rails close the gap against the locked ~720 center (`STATION_CENTER_COLUMN_CLASS`) — never a floating rounded card. Modal/intake, mobile, ambient AI, and station edge opt-outs remain explicit overlay contracts. **AI (header Sparkles) and record/ticket details share one right-edge slot** — detail outranks assistant; never a fifth permanent column beside both. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) (Right-rail modality · Frame column budget).
- **Scan stations that host a Workbench strip must expose a solid return-to-scan CTA** in `WorkbenchTrailingCluster.actions` (top-right of the pinned chrome — same row as, or above, any KPI display; never below it) on every strip tab. It **resumes** — re-opens the station's most recent record and re-arms the scan bar — it does not land a bare data table. Detail: [`display/workbench.md`](.claude/rules/display/workbench.md) → Multi-region pages.
- **Ops chrome is flush-square** — solid CTAs, tab bands, selects, chips and toggle rows compose `cornerClass('flush')` (`rounded-none`); soft radius (`rounded-lg`/`xl`/`2xl`/`full`) and horizontal pill bands (`HorizontalButtonSlider`, soft `TabSwitch`) are debt. `WORKBENCH_CHROME_PILL_CLASS` is now `cornerClass('flush')`. Band-1 host is `WORKBENCH_CHROME_BAND_FACE` (`gap-0 p-0`) — leading boxed cubes (Band-1 Pin-list when earned) abut the tab rail; never host `gap-2` / `p-0.5` air. `rounded-full` survives only for status dots · avatars · Switch tracks. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) (Workbench chrome flush).
- **Band-1 controls under ONE topic are TABS in one cube, never separated icons.** A chrome row that reads `[⇩] [☑] [+]` makes an operator parse three glyphs to find one job and spends three cells of the row the tab rail needs; the same verbs as **tabs inside a single cube** cost one cell and name themselves in words. Every chrome-row icon cell wears the one boxed face (`WORKBENCH_CHROME_CUBE_CLASS`, derived from `STATION_CONTEXT_BOXED_CUBE_CLASS` — same as carton Exit / Back-to-list), and a multi-verb cube composes `WorkbenchChromeCubeMenu`. Separate cells are correct only for genuinely different TOPICS — the leading Pin-list (which list is on this strip) is not the data cube, and the **return-to-scan CTA stays a solid Button** (the one control on the row that is not a utility). When both exist, trailing order is **`[ RESUME ] [+]`** — Plus data cube is always the far-right cell, to the right of the resume CTA (never `[+] [ RESUME ]`). Goldens: To-ship `OrdersSyncPopover` (Import · Add · Backfill) · Unbox/Arrival `ReceivingBoxChromeActions` (Add · Check · Export). Detail: [`display/workbench-ops-queue.md`](.claude/rules/display/workbench-ops-queue.md) → Trailing Display & Actions. Guard: `workbench-chrome-cube.guard.test.ts`.
- **Ops chrome binary show/hide is instant** — Workbench KPI Band 2 (and sibling sheet-chrome doors that free/occupy layout height above the grid) **snaps** open ↔ closed on the same frame. Never `collapseHeight`, opacity fades, or any layout tween that *pushes* the work surface open or shut — warehouse ops must feel snappy. In-content disclosures may still use sanctioned `collapseHeight`; chrome bands may not. SoT: `WorkbenchKpiBand`. Guard: `workbench-kpi-collapse.guard.test.ts`. Detail: [`source-of-truth.md`](.claude/rules/source-of-truth.md) → Workbench KPI Band 2.
