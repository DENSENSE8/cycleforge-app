# Scale ROI: "1M active users tomorrow + insane AI support"

Scope: operator sessions from 2026-09-24 to 09-28 (454 session files, 169 operator messages after dedupe), the incidents seen in this session, and a read-only codebase audit (3 audit agents; the top claims were re-checked by hand). **Today's baseline from the DB:** 9 orgs, 39 staff, 999 live sessions, 2,463 assistant turns, all on `local_mlx`. 1M users is about 25,000× today's load.

**Legend:** `[AI]` = AI-support item. **1-day** = can ship and be verified in one day. Effort: S = hours, M = 1–3 days, L = a week or more.

The tenant GUC is set per transaction with SET LOCAL, which is safe with the pooler. 327 of 381 tables use FORCE RLS, `app_tenant` has no BYPASSRLS, and CI checks the tenant-role invariant and IDOR tests. The proxy makes no DB call per request. The rate limiter is a distributed Upstash sliding window that fails open. The Upstash cache has org-scoped keys, tag invalidation and single-flight. Ably tokens are scoped to the org prefix. The chat route has TTFB discipline (only the limit and validation run before SSE), abort handling, a 15 s keepalive, in-turn failover, and a DB transaction per tool round rather than per turn. History is capped at 20 rows. Query embeds have a 300 ms budget with a keyword fallback. The search outbox embeds asynchronously. Integration crypto is AES-256-GCM, rotation works through `INTEGRATION_KMS_KEY_PREVIOUS`, and plaintext writes are refused in prod. The migration ledger is sha256-pinned with 0 pending. The Stripe and Zoho webhooks dedupe.
