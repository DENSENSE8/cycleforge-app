02 Colour — what the QA lab can prove

These are runtime CSS variables, so the Design Lab's data-reskin toggle moves them live on real routes. R1 transcribes each row into src/design-system/themes/ as --ds-color-<key>. Both schemes are complete on their own; nothing is inherited across the light/dark line.

Semantic keyDarkLight twinRole

Accent, page and the one rule about teal

KeyDarkLight twinRole

Teal is the accent and never means success. Success stays green and keeps its own hue distance, because on a status-heavy grid an accent that doubles as a state blurs the two at a glance. That is the failure mode the Studio direction was rejected for.

03 Radius, type, elevation — what the lab cannot prove

These are Tailwind classes resolved at build time. No runtime attribute moves them, so they land as R1 primitive commits through the :3051 worktree lane. Do not wire radius.ts into the Tailwind config to make the lab prettier: that remaps every rounded-* call site in the app at once.

Radius ladder — four rungs, and that is the whole set

Nesting is concentric by subtraction, not by a second ladder: an inner face inside a control with 2px padding takes calc(var(--r-control) - 2px). The seven-rung F9 ladder and every named corner exemption in radius.ts collapse into these five. Viewport-flush chrome stays square because a radius jammed against the display edge paints a corner of desktop wallpaper.

Every identifier and every number is mono with tabular figures and ligatures off. Plex Mono ligates fi and fl, which in a serial or FNSKU makes an operator transcribe a string that is not the one stored. Geist Mono is set the same way, deliberately.

Elevation — one raised step

flat

Ground plane. Borders carry the structure. Tables, rails, well grounds.

raised

Lightness step plus a 1px inner highlight. Panels, station cards, tiles. No drop shadow.

overlay

The only shadow in the system, and only for surfaces that genuinely float over content: popover, menu, dialog, the morph cursor layer.

This replaces F3's "no drop shadows, anywhere". F3 was already ignored by 346 shadow utilities, so the honest law is one shadow with a named job rather than a ban nobody kept. Density on a dark shell comes from lightness steps, not from ink.

Type size and target size never change with density. Handheld floors keep a 12pt type floor and 48dp targets, 10mm for a gloved hand. A density mode that shrinks the type is a legibility regression wearing a preference's name.
